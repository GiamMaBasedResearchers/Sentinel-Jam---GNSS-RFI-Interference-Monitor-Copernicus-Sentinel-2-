Data availability notice

Data availability — what to expect: Sentinel-2 GNSS RINEX files (AUX_GNSSRD) are published by Copernicus on a fixed schedule: every daily file lands about 5.5 days after the end of the day it covers (measured median 5 d 12 h ± 1 h; the daily batch is ingested around 12:00 UTC, same schedule for all Sentinel missions). The most recent ~5 days are therefore always missing from the catalogue — this is the normal publication pipeline, not a tool error and not a jamming effect. Genuine receiver failures remain detectable: a prolonged publishing stop is exactly the signature that revealed the S2A GNSS-receiver failure in Jan 2025.

Methodology

The Copernicus Data Space catalogue publishes Sentinel-2 auxiliary products as open data: RINEX files with onboard GNSS observations (AUX_GNSSRD), precise orbit ephemerides (AUX_POEORB) and attitude quaternions (AUX_PROQUA), queried here in real time via the public OData API — no login is needed to browse the catalogue (a free CDSE login — top bar — is only needed to download the binary files and run the RINEX content analysis below).

These are daily auxiliary files, not jamming events: typically 2–6 new files per day across the three types. Each coloured arc shows where the satellite approximately flew while the file was valid.

⚠ The red RFI zones are indicative (known GNSS-jamming hotspots from public reports), not measurements.
